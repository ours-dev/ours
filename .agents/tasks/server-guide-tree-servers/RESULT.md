A program that drives the `Server` itself must keep its own record of the channel; `LoopServer` looks the channel up first and never hits it (`loop_server.cpp:78`).
- A precedence the header leaves open: `Outgoing::add_protocol` checks the count before the name (`outgoing.cpp:32`), so a full table answers NoResource for an invalid name, while `outgoing.hpp:120` lists InvArgs first. No test pins it.
