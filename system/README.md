# System

This directory is used to put everything exposed to userspace.

## How to use it ?

**system/app**: Applications being used in userspace, programs that serve no protocol, such as shell, the serial console's.

**system/driver**: Device drivers, each a component the root starts, such as pc-ps2, the PS/2 keyboard's.

**system/lib**:  

**system/service**: Filesystem, Net Server and etc.
