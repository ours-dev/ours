# ours

## 1. Introduction

To master the complexities of kernel development and systems programming, I have conducted an in-depth study of industry-leading projects such as **Linux** and **Zircon**. The culmination of this journey is **ours** — a microkernel **modeled after** these proven architectures, designed to explore the next generation of OS design.

## 2. Technical Highlights

As an experimental project, **ours** embraces a **bleeding-edge** stack, adopting state-of-the-art technologies and solutions **to the fullest extent possible**. Key highlights include:

* ![C++](https://img.shields.io/badge/C++-23/26-00599C?style=flat&logo=c%2B%2B&logoColor=white)  
    **Modern C++ Standards**: Leveraging the latest C++ evolution, specifically focusing on **C++23** and the upcoming **C++26** for zero-cost abstractions and compile-time reflection.

* ![Bazel](https://img.shields.io/badge/Bazel-Build_System-43AF4A?style=flat&logo=bazel&logoColor=white)  
    **Next-Gen Build System**: Utilizing **Bazel** to ensure reproducible, fast, and scalable builds across different environments.

* ![Docker](https://img.shields.io/badge/Containerized-Development-2496ED?style=flat&logo=docker&logoColor=white)  
    **Containerized Development**: Full support for containerized workflows, ensuring a consistent and official-grade development environment for every contributor.
